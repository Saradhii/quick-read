# Web Page Summarizer Chrome Extension

## Description

This Chrome extension allows users to quickly summarize the textual content of the current web page they are viewing. With a click of a button, the extension extracts the main text from the page and **uses the Google Gemini AI model to generate** a short, bullet-point summary.

## Features

*   **One-click AI Summarization:** Summarize the active tab's content using Google's Gemini model.
*   **Text Extraction:** Attempts to identify and extract the main textual content from a webpage.
*   **AI-Generated Summary:** Provides a few bullet points highlighting key sentences/topics from the text, generated by AI.
*   **Loading Indicator:** Shows a "Summarizing with AI..." message while processing.

## Setting Up Gemini API Key

**IMPORTANT:** This extension now uses the Google Gemini API for summarization. You will need to provide your own API key for this feature to work.

1.  **Obtain a Gemini API Key:**
    *   Visit Google AI Studio at [https://aistudio.google.com/](https://aistudio.google.com/).
    *   Sign in with your Google account.
    *   Create a new project or select an existing one.
    *   Navigate to the API key section (often "Get API key" or similar) and generate a new API key. Ensure the Gemini API (or "Generative Language API") is enabled for this key/project.
2.  **Add the API Key to the Extension:**
    *   Once you have the extension files on your local machine, open the `background.js` file in a text editor.
    *   Near the top of the file, you will find the following line:
        ```javascript
        const GEMINI_API_KEY = 'YOUR_API_KEY_GOES_HERE';
        ```
    *   Replace the placeholder text `'YOUR_API_KEY_GOES_HERE'` with your actual Gemini API key. For example, if your key is `AbCdEf12345`, the line should look like:
        ```javascript
        const GEMINI_API_KEY = 'AbCdEf12345';
        ```
    *   Save the `background.js` file.

Without a valid API key, the summarization will fail.

## How to Install (for Developers/Testers)

Since this extension is not yet on the Chrome Web Store, you can load it as an unpacked extension:

1.  **Download or Clone:** Get the extension files onto your local machine.
2.  **Add API Key:** Follow the instructions in the "Setting Up Gemini API Key" section above.
3.  **Open Chrome Extensions Page:**
    *   Open Google Chrome.
    *   Type `chrome://extensions` in the address bar and press Enter.
4.  **Enable Developer Mode:**
    *   In the top right corner of the Extensions page, toggle the "Developer mode" switch to the **on** position.
5.  **Load Unpacked:**
    *   Click the "Load unpacked" button that appears.
    *   Navigate to the directory where you saved/extracted the extension files (the one containing `manifest.json`).
    *   Click "Select Folder".
6.  **Extension Ready:** The "Web Page Summarizer" extension should now appear in your list.

## How to Use

1.  Ensure you have added your Gemini API key to `background.js`.
2.  Navigate to any web page you want to summarize.
3.  Click on the "Web Page Summarizer" extension icon in your Chrome toolbar.
4.  In the popup that appears, click the "Summarize Page" button.
5.  A "Summarizing with AI..." message will appear. Please wait a few moments.
6.  The AI-generated summary will appear in the popup.

## How Summarization Works

1.  **Content Extraction (`content_script.js`):** When you click "Summarize Page", a content script is injected into the current webpage. This script extracts text from the page.
2.  **Sending to Background (`popup.js` -> `background.js`):** The extracted text is sent to the background script.
3.  **AI Summarization (`background.js`):**
    *   The background script takes the received text.
    *   It constructs a request containing the text and a specific prompt, asking the AI to summarize it into bullet points.
    *   This request is sent to the Google Gemini API (model `gemini-pro`).
    *   The API processes the text and returns a generated summary.
    *   The background script parses this summary and formats it as bullet points.
4.  **Display:** The summary (or any error messages from the API) is then sent back to the popup to be displayed.

The quality and content of the summary are determined by the Gemini model and the prompt used.
